在人工智能的汹涌浪潮中，很少有一家公司能像 Cursor 一样，在短短两年内从一个名不见经传的代码编辑器，崛起为 AI 编程领域的现象级平台，最终甚至与行业巨头 Anthropic 和 OpenAI 展开正面竞争。这期来自顶级风投机构 a16z 的圆桌讨论，邀请了深度参与 Cursor 每一轮融资的核心投资人，为你揭开这场惊人崛起背后的投资逻辑、战略判断与创始人哲学。

在投资人的眼中，Cursor 的故事远非一个简单的 "增长神话"。它是一场关于产品信仰的胜利，是对 "界面即核心" 这一信条的极致践行。在所有人都以为微软的 Copilot 将凭借其庞大的生态无可争议地赢得 AI 编码市场时，这家只有几个创始人的初创公司，是如何在看似死局的竞争中找到生存缝隙，并最终颠覆了整个市场格局？从对 "模型派" 与 "插件派" 的审慎思考，到坚决不做企业销售、直到 2025 年才以惊人速度补齐商业化能力，再到面对 Claude Code 等强大竞品时那份 "偏执但从容" 的态度——这场对话为你呈现的，是一场由顶级投资者解析的、关于技术洞察与商业艺术的深度案例。你将看到的，不仅是一个产品如何做到极致，更是一个时代如何在最前沿的领域被重新定义。

### 详细内容

#### 回溯 2024 年初：那个 "Copilot 时代" 的 AI 编程世界 `[对话开头]`

**核心观点**
在 2023 年底至 2024 年初，AI 编程领域虽然已初见成效，但格局与今天截然不同。领先的模型是 GPT-4、Claude 3 和 Llama 3，而主导性的编程工具是微软的 Copilot。那是一个智能代理（Agent）和推理能力尚未出现的 "远古时代"。

**深度阐述**
讨论一开始，投资人 Martin 就将大家带回了那个 "感觉像是很久以前" 的 2024 年第一季度。他特别回顾了当时的技术图景：当时的顶级模型是 GPT-4、Claude 3 和 Llama 3，这些在当时已经是相当出色的模型，但相比今天的能力，仍然显得原始。在编程工具方面，微软的 Copilot 以压倒性的优势占据了主导地位。

"当时领先的编程工具是 Copilot，而且领先优势巨大，这似乎是所有人的共识。微软正在施展他们的'微软魔法'——他们有 Copilot、有 Office、有 VS Code，所有这些结合在一起，看起来他们注定要赢得 AI 时代。" `[对话开头]`

在那个时期，虽然 AI 编程被证明是有效的，但和今天完全不可同日而语。Martin 提到，当时虽然有早期迹象表明你确实可以借助 AI 完成有意义的工作，但 "智能代理（agents）还不存在，循环（loops）机制还不存在，推理（reasoning）能力也基本没有"。这听起来像是一个疯狂时代的定义——一个充满无限可能，但还没有任何清晰路径的混沌初始状态。

**个人感受**
在这段描述中，我们能感受到投资人对于技术迭代速度的深刻敬畏。回想起来，这些对于今天而言仿佛是石器时代的工具，在当时却代表着最前沿的智能水平。这种快速的技术演进，为后续 Cursor 的爆发式增长奠定了背景——正因为所有基础设施都在剧烈变化，一个全新的、更好的产品范式才有机会打破旧有的垄断格局。

**延伸思考**
这段回溯的价值在于，它提醒我们，任何 "统治性" 的现状（如 Copilot 的主导地位）在技术范式的重大转型面前，都可能变得极其脆弱。永远不要低估一个坚定而又聪明的初创团队，在他们眼中，巨大的市场份额并非护城河，而恰恰是等待被颠覆的既定秩序。

#### 赛道上的光谱：模型派、插件派与中间路线 `[对话开头-中段]`

**核心观点**
当时，旨在通过 AI 改变编程的公司沿着一条光谱分布：一端坚信必须训练自己的基础模型，另一端则专注于以插件形式进行表面创新。Cursor 并非这两者中的任何一极，而是选择了一条 "界面" 路线，且在早期，这被证明是极其正确的选择。

**深度阐述**
Martin 接着指出，当时在 AI 编程的赛道上，存在着一个由不同策略组成的 "连续光谱"（continuum）。一端是那些认为 "赢得编程领域的唯一方法是构建一个基础模型，且这个模型必须专门为编程而生" 的公司。另一端则是那些很有远见地专注于智能代理（agents）的公司。而在两者之间，还有数以百万计在做插件（plugins）的公司。这些选择看起来都如此合理，并且分别由非常聪明的人在实践。

"这些新空间的有趣之处在于，聪明的创业者会出现，并做出真正有趣的事情。在这个案例中，训练模型是一个非常合理的事情，因为当时的模型在编程上确实不够好。有一种理论是，如果我们专注于这个领域，做一个专门用于编程的模型，那就会实现突破。而做插件的人则在说，'嘿，我们不要抛弃整个 IDE（集成开发环境），那太疯狂了，但人与模型之间的界面真的非常重要，所以插件是一个好去处。'"`[对话开头-中段]`

然而，最终被证明正确的，是像 Cursor 这样的中间路线。他们似乎被 "苦涩的教训"（Bitter Lesson，指AI研究中一个经验法则：利用算力与数据的方法最终会战胜人类手工设计的特征）深深影响。在早期，他们坚信："我们不需要在模型层面与 Anthropic 和 OpenAI 竞争，人与模型之间的界面才是关键所在。" 这种理念来自于他们的核心洞察——编程的未来将像 "伪代码"（pseudo code）一样。正如 Michael（Cursor CEO）常说的，当你翻阅老的计算机科学论文时，里面描述的算法往往是用伪代码而非实际代码。现在，模型已经强大到可以直接把那些伪代码实现为真正的程序。"将程序员的意图提炼到最小可能的规格说明（spec），这才是现在真正重要的事情。" `[对话开头-中段]`

**个人感受**
这是一个极具启示性的战略定位。在 AI 的狂热浪潮中，很多公司都被 "模型军备竞赛" 裹挟，认为不自己做模型就会被淘汰。但 Cursor 选择相信 "界面/产品" 是当下阶段的关键杠杆。这种清醒的自我认知，不仅是对市场环境的深刻洞察，更是对自身核心优势的清晰界定。他们承认模型的重要性，但明智地选择在此时此刻不将其作为自己的主战场。

**延伸思考**
这也引出了一个更深层的问题：在技术变革中，什么才是永恒的？模型会不断迭代，能力会不断提升，但人类与智能系统交互的方式、人类表达意图的方式，可能具有更长的半衰期。Cursor 的崛起证明了，在任何技术革命中，扎根本源的人机交互问题，往往比追逐底层技术本身更能创造巨大的商业价值。

#### 投资初印象：来自一线工程师的共鸣与创始人的 "否定哲学" `[对话中段]`

**核心观点**
Cursor 团队不仅在理念上与 a16z 的投资理念高度契合，更重要的是，它赢得了当时在 OpenAI、MidJourney、Replicate 等一线 AI 公司工作的顶尖工程师的青睐。在 90% 的投资会议时间里，创始人 Michael 都在礼貌而坚定地拒绝各种 "额外机会"，这种极致的专注力给投资人留下了深刻印象。

**深度阐述**
谈到最初如何被吸引，投资人们表示，他们与众多围绕编程进行创新的聪明人交流过，但 Cursor 团队 "脱颖而出"。这不仅因为他们认同 a16z 对世界的看法，更重要的是，"比我们更聪明的人"——比如当时在 OpenAI、MidJourney、Replicate 等公司工作的工程师们——都在使用并订阅这个产品。这种来自顶级智力圈的认可，是产品具备颠覆性的有力证据。

更让投资人震撼的是这个团队的 "特殊气质"（unusual degree of focus）。Matt 回忆道："我请 Michael 来给我们团队做了一次路演，那 90% 的会议时间，他都在说'不'。" `[对话中段]` 这种对于创始人而言非常罕见的特质，让 Matt 感到既好笑又印象深刻。因为通常，VC 们总会问一些关于 "你还可以做什么" 或者 "你与此有何关联" 的愚钝问题，而 Michael 则非常礼貌地听完所有问题后，平静地回答："嗯，有意思。不过，不，我们不会那样做。" 这种毫不含糊的专注，本身就是一种强大的信号。

**个人感受**
这种 "说不" 的能力，在如今这个充满诱惑和噪音的创业环境中，显得尤为珍贵。当一个创始人能够穿透所有噪音，清晰地认知并坚守自己的核心战场时，他的团队便拥有了一种巨大的内在确定性。它向内部团队传递了 "我们知道自己要去哪里" 的信念，也向外部投资人传递了 "我们不是机会主义者" 的信号。这是一种极端自信的表现，也预示了后来的所有战略决策都将是连贯且清晰的。

**延伸思考**
在投资人的故事中，他还提到了一个有趣的细节：当他努力说服 Cursor 团队拿投资时，他曾问 Michael 工作之外喜欢做什么。Michael 完全不理解这个问题，仿佛 "工作" 与 "乐趣" 对他而言是同义词。这让人不禁想到，在某些领域达到极致的人，往往已将自我实现与创造性工作融为一体。对于创业者而言，这种热爱是超越理性的护城河。

#### 产品信念的力量：为什么不做插件、不做企业版 `[对话中段]`

**核心观点**
面对投资人的疑问，Cursor 用一套极其理性的框架解释了他们的每个决策：因为人是通过自然语言与模型交流，所以编码模型本质上是在构建一个前沿语言模型，而不是一个小任务。此外，他们真正相信产品的力量——如果产品足够好，就会被广泛采纳；因此，他们不会去做受制于人的插件，也不会过早地服务企业。

**深度阐述**
当被问及 "是否担心无法获取企业客户" 时，Michael 给出了坚定的回应。投资人之一 Sarah 回想起当时的情景："他直视我们的眼睛，充满了高度的确信，然后反问了我们一个问题。" 这个 "反问" 本身，展现了他对自有逻辑的几乎无懈可击的信仰。

投资人 Martin 详细解释了这套逻辑。为什么不做编码专用的基础模型？"他们给出的理由是，你其实不是用代码与这些模型对话，你是作为人类用自然语言与它对话。因此，这个模型必须理解人类经验的广度。这意味着，构建一个编码模型，实际上就是在构建一个前沿语言模型，而这本身就是一件极其困难的事情。" 这个逻辑本质上是说，任何专注于狭窄领域的模型都无法满足通用的语言理解需求，最终都得走向通用人工智能（AGI），既然如此，何必从最难的起步点开始呢？不如先从应用层切入。

更关键的是他们的产品哲学："他们极度以产品为中心，这在 AI 领域里其实非常少见。他们真心相信，只要产品足够好，就会被采用。这种想法与马斯克（Elon Musk）的思维方式非常相似。"`[对话中段]` 这种信念直接决定了他们的战略选择：如果你真的相信产品本身的吸引力，那么你就绝不会去做插件，因为那样你就成为了别人产品的一部分。同样，如果你真的相信产品本身的价值，你就不会在早期分心去做企业级服务，因为最好的产品自己就是进入市场的引擎。

**个人感受**
这段分析展示了顶级投资人所见的 "清晰的逻辑闭环"。每个关键决策——不做模型、不做插件、不做企业——都并非源于短视或傲慢，而是从一个核心信念（产品为王）出发，推导出的必然结论。他们定义了 "我们是一家什么样的公司" ——一家解决产品问题的产品型公司，所有后续动作都是这一身份的延伸。这种一致性，与市场中那些试图 "什么都做" 的 "马赛克式" (pastiches) 公司形成了鲜明对比。

**延伸思考**
在创业的早期阶段，做减法比做加法更需要勇气和智慧。当你看到周围所有声音都在告诉你 "你应该做 X 因为别人都在做" 时，能够回到第一性原理，坚持自己 "为什么出发" 的理由，是区分卓越公司与平庸公司的关键。正如 Matt 所说，作为创始人，我们都想追求雄心壮志，将事业推到 "帕累托前沿"，但 "你必须知道曲线是什么"，并坚定地走在正确的曲线上。

#### 竞争迷雾：在 Copilot、Windsurf 和 Claude Code 之间穿行 `[对话中段-后段]`

**核心观点**
Cursor 从诞生第一天起就身处竞争旋涡的中心：他们有微软 Copilot 这个庞然大物，后有 Windsurf 在 YC 生态中的偷袭，再有 Cognition 在智能体领域的推进，以及最终 Claude Code 那压倒性的技术震撼。然而，创始团队始终保持着一种 "偏执但从容" 的心态。

**深度阐述**
在回顾创业历程时，投资人反复提到一个词——"竞争性的存在威胁" (looming existential threat)。Copilot 显然是最早也是最显眼的对手，它背靠微软，拥有成熟的企业级销售网络、开源权重（OpenAI）以及完全控制的 VS Code，庞大到几乎让人窒息。投资人 Sarah 直言，"如果看竞争格局的话，那几乎是荒谬的。" 技术老兵 Matt 也补充道："想想看，你居然想要去分叉（fork）一个微软拥有的东西（VS Code），然后用比他们还小的模型跟他们竞争？他们甚至拥有 OpenAI 的股权，还有强大的企业销售团队，以及前所未有的企业分发能力。他们拥有 1000 万开发者。他们拥有一切。"`[对话中段-后段]`

但正是在这种 "看似不可能" 的环境中，他们收集到了决定性的 "小数据点"。Martin 讲了一个故事：当时团队里一位成员与 Cursor 的一位创始人 Aman 共进晚餐，邻座恰是 Anthropic 的联合创始人 John Schulman。John 说，"我试过 Cursor，但我们的代码库（monorepo）立刻就把它的性能拖垮了，我甚至没法加载代码库。" 结果第二天，Aman 就对团队说，"我们做了一些改动，现在你（John）再试试。" 这种颠覆性的迭代速度，让投资人认识到，插件或是在 VS Code 上写一套东西永远是行不通的，因为 "世界上最聪明的人试过了，但失败了"。

此后，竞争者在不断变化：Windsurf 通过在 YC 生态中运作，吸引了一大批用户；Cognition 用智能体做出了出色的产品；直到 2025 年 5 月，Anthropic 的 Claude Code 横空出世，成功引发了整个行业的 "哦，糟糕"（oh sh*t）时刻。投资人对 Michael 提起了这款产品，Michael 的回答异常冷静："看，我们正在进军的是全球最大的市场。你总会遭遇强大的竞争对手。事实上，从最初开始，就有一长串的竞争者在轮番上阵。Copilot 是第一个，Claude Code 是一个不断轮换的角色阵容中的一个。我们相信，在巨大的市场中，你永远会遇到艰巨的对手，但这并不让我们感到恐惧。" `[对话中段-后段]`

**个人感受**
这段话是整场对话中最具震撼力的一刻。投资人表示 "被这句话的清晰度、那种无所畏惧的力量所震惊"。他们指出，这里有 "谦卑" 但也混杂着 "虚张声势" (bravado)，而 "这恰恰是当你面对巨头时，最可能赢的组合"。这种状态，正如亚马逊的贝索斯（Bezos）所展现的那样——当你足够聪明且方向正确时，这种清醒会赋予你一种近乎本能的自信和专注。与这种从容相伴随的，是创始团队极少被人看到的一点：极强的自我吞噬（cannibalization）能力。他们最先是一个 IDE，然后变成了一个 Agent 平台，再后来变成了一个模型平台，这种在两年内多次重构自己的魄力，在创业公司中是极其罕见的。`[对话中段-后段]`

**延伸思考**
面对竞争，大多数公司的第一反应是恐惧和防守。但 Cursor 的案例展示了另一种可能：当你的核心假设是 "我们将创造全新的、不可替代的用户体验" 时，竞争只是一种证明市场潜力的信号。竞争对手的每一次优秀表现，都在帮助你验证市场需求的真实性，并为你提供学习的方向，而不是动摇你存在的根基。

#### 增长叙事与商业化转身：从 "自服务" 到 "企业级" 的惊人跳跃 `[对话后段]`

**核心观点**
Cursor 的成长速度让传统投资模型失效。当投资人按惯例建议在 2500 万至 5000 万美元 ARR 时引入销售负责人时，Michael 直言 "自服务 (self-serve) 并没有枯竭"。但当他们决定进入企业市场时，他们的执行速度惊人，并以令人难以置信的效率建立起强大的销售引擎。

**深度阐述**
当被问到成长型投资（growth investment）的决策时，Sarah 指出，这其实是 "更不显然" 的决策。由于 Cursor 的 ARR 从 400 万增长到 5000 万只用了 4 个月，任何传统的增长率假设（如 5 年后自然衰减到 25%）都被彻底击碎。在传统增长模型中，你要假设销售团队扩容、销售周期拉长等，但 Cursor 的表现完全跳出了常规曲线。"我记得当我们将一些假设摆到 Michael 面前时，比如 '我们帮你找个销售负责人吧'，他看着我的眼睛说，'自服务并没有枯竭。'"`[对话后段]`

因此，在早期，他们甚至设立了 "enterprise@cursor.com" 这样一个简单粗暴的邮箱，用以筛选企业需求，而并不急于主动出击。这种逆常规的思维，让投资人们被迫 "抛弃了那些历史上会用于增长模型的假设"。

但真正的转折点发生在他们决定进军企业市场之后。Martin 分析道，因为他们学习能力极强，意识到只有在企业端才能实现最大的商业价值（margin），也是未来长期可行性的关键。于是，当他们决定行动时，他们的执行力令人恐惧。"那可能是人类历史上最快组建销售团队的速度之一。"`[对话后段]` 这一动作的执行细节完美印证了 "你如何做一件事，就如何做所有事" (How you do anything is how you do everything) 这句格言。他们在招聘销售人才时，使用的不是传统方式，而是将 Cursor 对产品的研究精神（intense research）应用于人力资本：他们会研究 "哪 10 家公司在这类销售中表现最出色，然后深入其中的 10 支团队，再锁定那个排名第一和第二的、真正推动变革的销售工程师"。他们极度依赖深度背景调查，不仅是直属领导，而是 "老板的老板的老板" 的认可。这个流程细致到令人惊讶。其结果就是，Cursor 在不到两年的时间内，便渗透进了超过 50% 的财富 500 强公司。`[对话后段]`

**个人感受**
这段经历打破了 "技术驱动公司不懂销售" 的刻板印象。Cursor 证明了，如果你拥有一个极其清晰的产品信仰和一套强大的学习系统，你几乎可以将这种能力复制到公司的任何职能领域。他们没有像传统公司那样，先有销售，再定义产品；而是先用产品定义了一切，然后用同样卓越的标准从零构建销售。这种逻辑的延展性，远比单纯做一个好产品本身更伟大。

**延伸思考**
在 SaaS 领域，常见的发展路径是 PLG（产品驱动增长）到 SLG（销售驱动增长）的线性演进。但 Cursor 展示了一种新的可能性：超高速的 PLG 可以为公司赢得一张 "自定义未来" 的门票。因为公司拥有极高的人员效率和极致的口碑传播，它无需过早地引入沉重的销售体系，可以在一个更有利的时机（产品验证充分、市场地位巩固后）再以一个极高的标准建立强大的 SLG 引擎。这种 "延迟满足" 与 "全力一击" 的组合，是打破增长悖论的一把钥匙。

#### 文化、人才与 M&A：用招聘与设计定义公司 `[对话后段]`

**核心观点**
Cursor 的创始人群体不仅热爱写代码，更懂得以 40% 的时间招募人才，将招聘当作一种文化渗透，并细致到用办公室里的设计来体现自己的价值观。他们精通通过人才收购（acqui-hires）来扩充能力，整合创始人的能力令投资人叹为观止。

**深度阐述**
深入了解后，投资人发现 Cursor 文化的核心并非 "工作狂" 式的自我消耗，而是一种与心流和兴趣同构的状态。正如一位投资人所言，"他们这样做不是因为被工作束缚，而是因为他们真的爱写代码，爱系统本身。" 然而，这形成了一个巨大悖论：他们如此专注于产品，却在另一头，他们对招聘、Go-to-market 和商业模式的投入也极为惊人。尤其是创始人将 40% 的时间（创始团队每人都是如此）用在招聘上，这在投资人们看来是 "从未见过的" 惊人投入。`[对话后段]`

这种投入在组织设计上结出了硕果。他们聘请的不仅是普通员工，更是大量成功的创业者。投资人提到了 Koala 的创始人 Tito 和人才岗位的 Adam Ward 等案例，认为 Cursor 是 "如何整合创始人，并让其迅速与公司文化融合并放大价值" 的典范。这种依赖于自身强大文化同化能力的策略，通常被认为是 "操作上极其复杂和困难" 的，但 Cursor 因为文化足够清晰和强大，所以敢于吸收和同化那些拥有"创始人视角"的顶尖人才。

此外，这种追求极致的精神也延伸到物质空间。"我记得走进他们的办公室，心里就想：我要是20岁出头，绝不会想到在天花板上挂这些暖色串灯。" 办公室的 "无鞋" (no-shoes) 文化，来自北欧风格的二手家具，这些细节共同营造了一个让人想全天候留在那里的空间。他们甚至对市场营销活动极度克制："我们不作 X（Twitter）上那种发声，那不是我们的声音。我们从不做垃圾式营销。" 这样的决定，本质上是在用做产品的态度做品牌，是一种精益求精的美学管理。

**个人感受**
这些细节揭示了 po 最容易被忽略的一部分——创始人的审美。在创业的早期，创始人不仅是 CEO，更是这个公司的首席文化官（Chief Culture Officer）。他们通过自身的注意力分配（如 40% 的时间用于招聘）和审美偏好（如办公室的布局），无声地定义了 "什么样的人适合这里" 以及 "我们如何看待工作与生活"。这远比任何精心撰写的文化手册都更有力量。

**延伸思考**
在 AI 领域，顶尖人才的身价已经水涨船高。Cursor 的例子表明，想要吸引这类人才，只靠高薪已远远不够。他们需要的是一个能够理解自己、尊重自己、并且能在模糊与不确定中提供稳定价值观的组织。通过刻意设计组织与空间，创始人可以在企业生命周期的最早期就建立起一种难以言说的 "文化引力场"，这才是人才长期留任的根本。

#### 与马斯克的共同点：从 SpaceX 到 Cursor 的终极自信 `[对话后段]`

**核心观点**
Cursor 的战略选择、文化内核与 Musk 的 SpaceX 有诸多惊人相似之处：大市场的想象、面对绝境式竞争的不屑、对产品/工程文化的极度自负，以及鲜明的 "逆流而行" 气质。这种深度的同构性，使得双方的 M&A (合并与收购) 几乎是一种天然的匹配。

当讨论声量逐渐向 Cursor 与 xAI 的合并（M&A）转移时，投资人们指出，这种共同的 "文化基因" 是这笔交易能够成行的关键。一位投资人回忆，在 2019 年见 SpaceX 团队时，他们虽然还在做火箭发射，但目标却是 "全球通信" 和 "为世界上的每个人提供互联网"。"当时他们一颗 Starlink 卫星都还没发射上天。" 这与 Cursor 团队在早期就声称将改革编码方式、并在后来一次又一次超越自己预期目标的轨迹如出一辙。`[对话后段]`

**延伸思考**

### 精华收获

1.  **界面是终极护城河**：在底层模型能力爆炸的时代，人与模型之间的 "界面" 是决定用户体验的关键。能够将人的意图极致压缩为 "最小规格说明" 的产品，将拥有巨大的竞争优势。
2.  **以 "不做" 定义战略**：对自己想要解决的问题有清晰的认知，可以极大地简化战略选择。无论是 "不做模型"、"不做插件" 还是 "早期不做企业"，都是基于这一核心信念的必然结果。学会说 "不"，是创始人最被低估的战略能力之一。
3.  **极致的聚焦带来极致的速度**：当创始人将 100% 的精力（甚至 40% 的时间专门用于招聘）投入到一件事上时，所爆发出的能量可以摧枯拉朽。这种专注不仅体现在产品上，也体现在人才、品牌、空间设计等所有环节。
4.  **打破传统增长模型的勇气**：Cursor 证明了在超高速增长的 AI 原生领域，传统 SaaS 的里程碑（如何时引入销售VP）可能已不再适用。自我服务并没有枯竭，产品本身可以成为最强大的增长引擎。
5.  **文化是应对巨头竞争的心理锚点**：面对 Copilot、Claude Code 等强大的竞争对手，真正让公司稳健前行的不是焦虑，而是一种 "偏执但从容" 的心态。这种心态来源于对自身文化和战略的深度认同。
6.  **人才战略是终极杠杆**：通过极其严谨的 "研究型" 人才搜寻（深入的前员工背景调查），以及大胆吸收创始人并将其顺利融入，Cursor 证明了在 AI 时代，人才获取与整合能力本身就是一种顶级的企业核心竞争力。
7.  **技术转型先于商业模式**：面对外界关于商业模式的批评，投资人坚持 "技术转型总是先于商业模式发生"。只要你拥有海量用户与数据，商业模式的建立可以在恰当的时机以极快的速度完成。

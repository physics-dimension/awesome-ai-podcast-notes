## 开篇引入

> "我如今在 token 上的投入，超过了在知识型员工上的投入。"

这句听起来近乎极端的话，出自 Kavak 的 AI 负责人 Ali Masa 之口。它不是一句姿态性的豪言，而是一家拥有千万级客户、业务横跨二手车买卖、金融、保险与物流的拉美巨头，在过去三年里真实执行的组织战略。Kavak 没有把 AI 当作辅助工具，而是把整个公司"押上去"——每天有 10 万到 20 万个 AI Agent 被实例化，96% 的客户交互由 Agent 完成，95% 的交易全程由 Agent 处理，AI 销售员的转化率是人类团队巅峰水平的 2.1 倍。更疯狂的是，他们让 AI 担任一座真实墨西哥城市的"总经理"，六周内把利润拉高了 50%。

这不是一个关于"如何部署 AI 工具"的故事，而是一个关于"如何把公司推倒重来"的极端案例。对于任何正在思考 AI 战略的企业领导者、创业者或从业者来说，Kavak 的经验既是一份操作手册，也是一面照出自身犹豫的镜子。

## 一、从 2013 年的"机器学习"到 Kavak：一位超前十年的创业者 `[访谈开场·嘉宾背景]`

**核心观点**

Ali Masa 在 ChatGPT 出现之前十年就已经是机器学习的坚定信徒。他创办的 Oppy Analytics 服务了多家财富 500 强企业，但直到 Transformer 架构和 ChatGPT 真正到来，他才意识到：自己等待的那个"可以重建一切"的时刻，终于来了。

**深度阐述**

"我们当时称之为机器学习，那是完全不同的一族算法。" Ali 回忆道。2013 年，他和团队带着一个非常宏大的愿景创立了 Oppy Analytics——他们相信，新的机器学习模型会强大到足以解决任何复杂问题。这在当时是"前 Transformer 时代"，深度学习还没有展现出横扫一切的威力。他们为财富 500 强企业构建了风险算法、物流预测、营销优化等系统，公司做得相当不错。

但 Ali 坦言："我想我们比时代超前了十年。"这种超前意味着，技术底座还不够成熟，很多构想无法在真实商业场景中兑现。直到 Transformer 架构出现，再到 ChatGPT 时刻的到来，一切突然变得清晰：现在可以构建一个全新的公司，以及一种全新的构建公司的方式。正是在这个转折点上，Ali 与 Kavak 的创始人 Carlos 走到了一起，决定把这种"全新方式"付诸实践。

**个人感受**

Ali 在讲述这段经历时，语气中既有对"超前十年"的无奈，也有一种"终于等到这一天"的释然。这种感受对许多深耕 AI 多年的从业者来说应该不陌生——技术浪潮真正到来时，那些最早就站在海边的人，反而最清楚眼前的浪意味着什么。

**延伸思考**

"超前十年"与"提前一分钟"之间的差别，往往不是认知问题，而是基础设施问题。Oppy Analytics 的案例提醒我们：在没有 Transformer 的时代，即便你看到了机器学习的潜力，垂直场景中的数据、算力和模型能力也不足以支撑宏大的愿景。今天的创业者可能同样面临着"过于超前"的风险，也面临着"终于等到"的窗口——关键区别在于，当前的模型能力已经足够让一个五人团队构建过去需要五百人才能做出的产品。

## 二、Kavak 的垂直整合帝国：为什么拉美二手车市场需要一切从零搭建 `[对话·业务背景]`

**核心观点**

Kavak 表面上是二手车交易平台（买车、翻新、卖车、提供融资），但为了服务好客户，它被迫自己建造了金融科技公司、物流公司和类似 Carfax 的基础设施——因为拉美市场上这些东西根本不存在。

**深度阐述**

在与 a16z 主持人的对话中，Ali 用一段简洁的话勾勒了 Kavak 的业务版图："Kavak 最初是一个二手车市场用例。我们买车、翻新、销售并提供融资。"如果只做表面上的"中间商"，故事到这里就结束了。但 Kavak 很快发现，在拉丁美洲，没有任何现成的中间基础设施可以依赖。没有可靠的车辆历史记录服务（类似北美的 Carfax）、没有足够高效的物流网络、也没有针对二手车场景的成熟金融服务。

"为了以正确的方式服务客户，我们不得不垂直地建立一切。" Ali 说道。这意味着 Kavak 同时是一家二手车零售商、一家金融公司、一家保险公司分销商和一家物流运营商。这种"重资产"模式看似笨重，却为后来的 AI 转型埋下了关键伏笔：因为所有环节的数据、流程和系统都在自己手里，当 AI 时代到来时，Kavak 拥有了一个别人难以复制的、完整的数字化底座。这也是为什么 Ali 后来能够说："我们问自己的问题是——如果我们拥有 GPT-10 级别的智能，2035 年的 Kavak 应该长什么样？"

**延伸思考**

垂直整合在过去常被视为"重模式"的缺点，但在 AI 时代它突然变成了一种战略资产。当 AI Agent 需要调用公司每一个系统的 API 时，那些拥有完整数据闭环和系统控制权的公司，将比依赖外部生态的"轻公司"更容易构建端到端的自动化。这也解释了为什么很多互联网平台公司在 AI 转型中反而步履维艰——它们的核心流程并不在自己的掌握之中。

## 三、核心架构：一客一 Agent，每个客户都有属于自己的"数字员工" `[对话·架构设计]`

**核心观点**

Kavak 没有采用业界常见的"多 Agent 专家系统"或"工作流自动化"，而是选择了一种更激进的架构：为每一位客户实例化一个专属于他的 Agent，每个 Agent 拥有自己的虚拟机、完整的记忆、长期目标和一套可以调用全公司所有工具的操作界面（CLI）。

**深度阐述**

当主持人问出那个关键问题——"一个客户从进来卖车到完成交易，会接触到多少个 Agent？"——Ali 的回答直接揭示了 Kavak 的底层范式。

"我们把公司押在了'由 Agent 运营的公司'这个转型上。我们问自己的问题是：如果有 GPT-10 级别的智能，2035 年的 Kavak 应该怎么建？"答案是一个与今天截然不同的架构：当客户进入 Kavak 的系统时，一个专属 Agent 会被"凭空创造"出来，它拥有独立的虚拟机，能够记住这个客户与 Kavak 多年来的每一次互动——浏览过哪些网页、两年前打过的一通电话说了什么——全部都存在它的记忆里。

这个 Agent 不是被动等待指令的聊天机器人。它会制定策略、设定长期目标——核心目标只有一个：最大化这个客户的终身价值（Lifetime Value）。为了实现这个目标，它可以做任何必要的事情：让客户满意、推动客户尝试 Kavak 的不同产品（卖车、买车、贷款、保险），并且跨时间地维护这段关系。

"这是一种全新的、规模化的突破性架构。" Ali 强调。业界大多数人还在构建"专家型多 Agent 系统"——让一个 Agent 负责金融、另一个负责保险，再通过编排层把它们组合起来。Kavak 曾经也是这么做的，但他们最终意识到：与其用"工作流"（workflow）来约束 AI，不如押注"带硬目标的长期运行 Agent"（long-running agents with hard goals）。后者才能真正最大化客户满意度和终身价值。

**视觉/结构信息描述**

这里描述的架构可以简化为一张结构图：
- **前端入口**：客户进入 Kavak 网页/电话/任何触点
- **Agent 实例化**：系统为这位客户生成一个专属 Agent，分配独立虚拟机
- **记忆层**：存储客户多年历史交互数据
- **目标层**：设定长期目标（最大化客户终身价值）
- **工具层**：Agent 通过 CLI 访问公司所有 API 和技能
- **执行层**：Agent 自主规划、执行任务，必要时向人类请求帮助

**延伸思考**

"一客一 Agent"与"一任务一 Agent"的本质区别在于：前者把 AI 视为一个长期关系的管理者，后者把 AI 视为临时工具。Kavak 的选择背后是一个商业判断——他们在卖的是二手车和个人贷款，客单价高、决策周期长、信任建立至关重要。只有"了解你、记住你、为你长期规划"的数字员工，才能真正完成这种高信任度的交易。这也提示其他行业：Agent 的架构设计不是技术偏好问题，而是商业模式的外化。

## 四、三大关键决策：为什么"给员工发 ChatGPT"毫无意义 `[对话·转型方法论]`

**核心观点**

Kavak 的 AI 转型建立在三个几乎违背直觉的决策上：第一，公司结构必须为 AI 推倒重来，而不是在旧结构上叠加 AI 工具；第二，敢于把尚未完美的 Agent 直接放到客户面前，用真实数据训练它；第三，把公司的成功指标从"交易量"改为"客户关系价值"。

**深度阐述**

Ali 观察到，很多公司陷入了一个共同的陷阱："第一个本能反应是——好吧，让我们采用 AI。你保持现有结构不变，把 ChatGPT 发给团队。然后什么效率提升都没有发生，客户面对的还是同样的问题，一切照旧。"原因很简单：旧的组织结构是为旧的能力设计的。一个以人类沟通、人类决策、人肉协作假设为前提的公司流程，不会因为员工多了一个 AI 工具就产生质变。

因此，Kavak 做出了第一个决策：**围绕 Agent 重新设计整个公司**。这意味着重写公司的大部分 API，重建系统，让 Agent 能够调用它们执行任务。Ali 直言不讳："这实际上意味着重建你公司的大部分肌体。"这不是 IT 项目，而是业务重构。

第二个决策是：**主动创造数据与反馈循环**。"让 Agent 真正有效的唯一方法，是你教会它们。怎么教？把它们放到开放环境里，放到真实客户面前，拿到真实数据，建立评估体系（evals），然后训练它们。" Ali 将其称为 Kavak 的第二个赌注——他们相信可以构建"超人类 Agent"（superhuman agents）。"这意味着在每一个重要的维度上——转化率、终身价值、客户体验——我们的 Agent 将超过我们曾经雇佣过的最优秀的员工。"所以他们把 Agent 直接放在了最难的问题面前：卖车。不是从客服这种"低风险"场景开始，而是从公司最核心、最困难的创收环节开始。

第三个决策是：**改变公司成功的度量方式**。Kavak 过去是一家"交易型公司"——衡量的是买了多少辆车、卖了多少辆车、需要采购多少刹车片。现在它变成了一家"关系型公司"：数据库里有 1000 万客户，其中大部分被分配了专属 Agent，任务就是最大化他们的终身价值。Ali 算了一笔账：Kavak 卖的是车和个人贷款，都是高客单价产品，"只要激活 1% 的客户池，就是数亿美元的机会。"对于高信任、高客单价的行业来说，这种转型的赌注是完全合理的。

**精华收获**

- 不要给旧组织配新工具，要为新技术重建组织
- 不要等 Agent 完美了再上线，把它们放到真实场景中，用反馈训练它们
- 不要只衡量交易，要衡量关系——AI 的最大杠杆在于长期客户价值

## 五、Evals 至上：速度的刹车片，也是信任的基石 `[对话·评估体系]`

**核心观点**

Kavak 的规模化秘诀是"以评估为中心"：他们在评估体系上投入的工程师时间、token 和金钱与构建 Agent 本身一样多。Evals 不是事后诸葛，而是让公司敢踩油门的刹车系统。

**深度阐述**

先看一组数字：每天有 10 万到 20 万个 Agent 被实例化；它们"醒来"后可能工作 3 分钟、8 小时甚至 3 天，然后给自己设一个闹钟，在下一个任务时间到来时再次醒来；96% 的所有客户交互由 Agent 处理，95% 的交易完全由 Agent 处理（只有交车时会有真人递给你钥匙）。这种规模听起来近乎科幻，但它正运行在墨西哥和其他拉美市场。

Ali 用了一个精妙的比喻来解释这种规模背后的方法论："我喜欢快速行动，但要想快，你必须先有刹车。想象一辆车——只有当刹车足够好时，你才敢踩油门。AI 超级强大。我看到很多公司搞砸了，就是因为他们没有好的刹车，于是只能小心翼翼地慢行。而我的思路恰恰相反——我们能多快？取决于我们的 evals 质量有多高。"

Kavak 的经验法则非常具体：**在构建 evals 上花费的时间、token 和金钱，与构建 Agent 本身一样多**。"Evals 绝不能是事后才想起来的东西。"那评估什么？首先，最重要的是商业结果：客户是否满意、是否买了车、贷款是否获批、是否把车卖给了我们。Ali 批评了很多公司使用的表面化 KPI："它们衡量通话数量、通话时长之类的肤浅指标——这些给你一些信息，但根本没有用。重要的是这个客户是否转化了？是否从服务中获得了价值？之后是否愿意再次与我们互动？"一旦这些 evals 建立起来，剩下的就是不断优化 Agent 架构，给 Agent 更多技能去服务千万客户。

**个人感受**

Ali 对表面 KPI 的鄙视是直白而真实的。他见过太多公司用"使用了 AI"或"处理了多少通电话"来粉饰太平，却回避了那个最根本的问题：AI 有没有让生意变得更好？这种"结果导向"的执拗，或许正是 Kavak 能把 AI 从"成本中心"变成"利润中心"的关键。

**延伸思考**

"Evals 是刹车"这个比喻值得反复咀嚼。许多企业在 AI 转型中感到"不敢快"，真正的瓶颈不是模型能力，而是缺乏可靠的评估体系。没有评估，你就无法区分一次成功是运气还是系统能力；有了评估，你才能像 Kavak 一样，每天让 20 万个 Agent 独立做出影响真实客户的高风险决策。

## 六、AI 是更好的销售员：转化率 2.1 倍，NPS 翻三倍 `[对话·销售场景]`

**核心观点**

Kavak 从未构建"客服 Agent"——他们从一开始就构建"销售 Agent"。在拉美卖一辆车需要精通 15 种不同技能（选车、融资、保险、置换评估等），AI 把这 15 个专家融为了一体，并且超越了他们每一个。

**深度阐述**

主持人问了一个直击本质的问题："你们真的让 Agent 直接面对客户做销售吗？" Ali 的回答带着一种"当然"的底气："我们从来没有构建过客户支持或客户服务 Agent。我们构建的是销售 Agent。"

在拉美卖车有多难？想象一下：客户面对 2 万个可选的车型（SKU），需要选择融资方案并完成整个审批流程，还要考虑保险和覆盖范围。很可能这位客户还有一辆旧车想置换——所以还要给那辆车估价。这不是一个简单的销售动作，而是一个由 15 个专家角色协作完成的复杂流程。在 2020 到 2021 年，Kavak 的做法是让客户分别与融资专家、购车顾问、收购专家、保险专家沟通，最后拼凑出一个方案。这种体验对客户来说极其繁琐。

Kavak 的第一步，不是让 AI 从头到尾处理整个流程，而是问："我们能构建一个在每个单项上都比领域专家更优秀的 Agent 吗？"然后把它们组合成一个"超级专家"——一个同时精通保险、融资、购车建议的 Agent。这正是他们最终放在客户面前的东西。

结果令人震惊。客户满意度（NPS）提升了三倍。上线初期，Agent 的转化率已经比人类团队高出 50%；而如今，转化率稳定在人类团队水平的 2.1 倍以上。为什么 AI 能成为更好的销售员？Ali 给出了几个关键词：**专家级知识、无限的耐心、完整的客户记忆、长期规划能力、永远不会疲惫**。而最可怕的优势在于反馈循环："如果它犯了一个错误，它会学到教训，第二天，不仅它自己，其他 20 万个 Agent 也都学会了。"人类销售员的经验只能通过漫长的培训复制，AI 销售员的经验可以在一个晚上复制到整个军团。

**精华收获**

- 别用 AI 做客服——用 AI 做销售，把 AI 放在公司最难、最核心的创收环节
- AI 销售员的优势不是"替代人类"，而是"记住一切 + 永不疲倦 + 集体进化"
- 高客单价、长决策链、高信任需求的产品，恰恰是 AI 最该上场的地方

## 七、AI 重构金融服务：三分钟批贷 vs 两个月的行业常态 `[对话·金融场景]`

**核心观点**

Kavak 将 AI 用在了严格的受监管金融服务中：汽车贷款通常能在 3 分钟内获批，而墨西哥等新兴市场的行业常态是两个月以上。AI 根据客户与车辆的全量数据实时定价风险，并且可以在客户还不起贷款时主动提供降级方案。

**深度阐述**

两位主持人都敏锐地注意到，AI 做客服已经逐渐被世界接受，但"AI 端到端地做受监管金融服务"仍是一个许多人认为不可能的事情。Kavak 恰恰在证明这个判断是错的：他们用 AI 做信用评估（underwriting）、给无信用记录或薄信用记录（thin/no file）的客户定价、做贷后服务。

Kavak 推出的第一个金融产品是车贷。在墨西哥和一些新兴市场，传统车贷审批需要两个月甚至更久。Kavak 的 AI 通常在 3 分钟内完成审批。秘密在于他们拥有海量的客户与车辆数据——客户多年来的行为数据、车辆的历史和状况数据。更重要的是垂直整合带来的灵活性：如果客户还不起贷款了，他们可以把车还给 Kavak，Kavak 给他换一辆更便宜的车、每个月支付更低金额，"他们就能脱离困境"。这种服务能力是传统银行根本无法提供的。

当 Kavak 开始推出其他金融产品（比如大额个人贷款）时，他们进一步意识到：买车和贷款对客户来说是重大人生决策，通常要花三到四个月才能下定决心。如果能在这个过程中深入了解客户、让流程变得轻松，转化率和留存率就会飙升。AI 可以做到这一点——根据客户的独特情况，个性化地定制利率、风险和最高贷款额度，既照顾整个投资组合的健康，又针对每个客户的真实风险水平和外部环境（比如客户收到的其他报价）进行优化。

**延伸思考**

Kavak 的金融案例揭示了一个重要规律：AI 在金融领域的优势不仅来自模型能力，更来自**数据生态**。传统银行的审批慢，不是因为模型不够好，而是因为它们缺乏与客户的深度互动数据。Kavak 因为有交易场景、有车辆数据、有客户关系历史，AI 才能在 3 分钟内做出负责任的信贷决策。这提示所有金融机构：AI 金融的核心壁垒，在于你能否构建一个围绕客户的全维度数据闭环。

## 八、"AI CEO"实验：在一个真实城市里，让 AI 当总经理 `[对话·AI 管理实验]`

**核心观点**

Kavak 做了一个几乎疯狂的实验：在墨西哥城市库埃纳瓦卡（Cuernavaca），他们把一个 Agent 放进管理者的位置，让它担任这座城市的"CEO"。六周后，它没有实现"利润翻倍"的激进目标，但利润增长了 50%——而且几乎每一项 KPI 都在变好。

**深度阐述**

当 Kavak 决定围绕 AI 重建公司时，他们追问了一个更远的问题："AI 能不能做 CEO 的工作、做领导层的工作？"诚实的答案是：以现在 AI 的改进速度，2035 年它很可能可以。于是他们决定——"现在就试一试"。

"我们在墨西哥划出了一座城市，库埃纳瓦卡。我们把一个 Agent 放进我们的一个 harness（编排系统）里作为 CEO。它开始学习，开始做决策，并评估这些决策。" Ali 透露，这个 AI CEO 已经运行了六周。第一个月的目标是把这家分公司的利润翻倍。它没有达成——但达成了 1.5 倍，也就是利润增长 50%。

这个结果让 Ali 自己都觉得"太疯狂了"。"人们都说 CEO 是 AI 最后一个会取代的工作——不，它真的不是。"他描述这个 AI CEO 的工作方式："它像一个超级聪明的人，菲尔兹奖级别的聪明，深入每一个数字、每一个客户，做出完美的预测，然后微观管理每一天必须执行的每一件事。"它会给库埃纳瓦卡的所有一线员工发送消息，告诉他们当天的工作计划，并要求他们以语音留言的形式汇报进展。客户满意度上升了、库存管理更好了、库存周转更快了、金融渗透率提高了——"每一个 KPI 都开始改善。"[对话中段]

**个人感受**

Ali 在讲述这段经历时带着毫不掩饰的兴奋与震撼。他承认结果超出了自己的预期——一个 AI 管理者不仅没有被数据淹没，反而展现出了一种"近乎逼迫式"的执行力。这让人不禁思考：当 AI 不只是执行者，而是拥有目标、规划和考核权的管理者时，组织的权力结构将如何被彻底重塑？

**延伸思考**

AI CEO 实验引发了一系列深层问题：当一个 AI 拥有管理人类员工的权力时，员工的工作动机、忠诚度和心理安全会发生什么变化？Kavak 的答案是员工满意度反而提高了——可能是因为 AI 的指令更清晰、更公平、更基于数据。但样本还太小，时间还太短。这个实验的真正意义在于：它把"AI 能否做管理工作"从一个哲学问题变成了一个可验证的假设。

## 九、物理世界的协作：机械师、Ratatouille 与"El Mike" `[对话·物理场景]`

**核心观点**

并非所有工作都能被 AI 完全替代。Kavak 在墨西哥约有 800 名机械师，双手的灵巧性和感官判断极难被 AI 取代。Kavak 的做法是给机械师配备一个"AI 搭档"——如同《料理鼠王》里的小老鼠——让 AI 指导检查流程、提供实时建议，结果保修成本下降了 20-26%。

**深度阐述**

Ali 坦诚地划分了 AI 能力的边界："有些工作我们仍在培训和雇佣人类——那些与物理世界相关的工作。"Kavak 在墨西哥大约有 800 名机械师。车辆检修需要大量的灵巧操作和感官判断（看、听、摸），这些能力目前极难被 AI 替代。但 Kavak 没有把这部分业务排除在 AI 转型之外，而是用构建其他 Agent 的同一套 harness，给机械师们配备了一个"搭档"。

这个搭档叫 "El Mike"。Ali 用了一个绝妙的类比来解释它的工作方式——就像电影《料理鼠王》中的老鼠（Remy）和人类厨师（Linguini）的合作关系：AI 不是站在前台，而是躲在帽子里，告诉人类厨师该怎么做。El Mike 会告诉机械师如何检查一辆车，给出技巧、展示正确的操作方式。

结果同样是惊人的：检查质量大幅提升、检查速度更快、维修速度更快、成本更低。最重要的是，交付的车辆质量更高了——"自从上线以来，保修成本下降了大约 20% 到 26%，客户满意度也再次上升。"[对话中段]

**延伸思考**

"AI 替代人"与"AI 增强人"并不是互斥的，Kavak 的机械师案例展示了一种更务实的路径：AI 负责"知识"，人类负责"动作"。随着具身智能和机器人技术的进步，AI 的能力边界会不断外推，但至少在今天，"人机协作"依然是物理世界的最高效方案。而 Kavak 的可贵之处在于：他们没有因为某个岗位"不容易被 AI 替代"就放过它，而是想尽办法用 AI 把这个岗位上的每个人都变得更强。

## 十、Jedi Academy：从 CEO 到机械师，全员六周变身 AI 建造者 `[对话·人才培养]`

**核心观点**

Kavak 创办了名为"绝地学院"（Jedi Academy）的内部训练营，从 CEO 到 AI 工程师再到机械师，所有人都要参加。六周后，学员就会把生产级 AI Agent 部署上线。这是 Kavak 面对"每个人工作都会改变"这一问题给出的答案：不是逃避，不是裁员，而是全员武装。

**深度阐述**

主持人提到了硅谷正在热烈讨论的问题：未来的组织会长什么样？人类在其中扮演什么角色？Ali 的回应非常直接：三年前他们就认真地问过自己这个问题，得出的结论是——"每个人的工作都会改变。"

"我们两三年前做的事情，很可能都会被 AI Agent 做得更好。"这句话听起来像是一个死刑判决，但 Kavak 把它变成了一份训练令。于是他们推出了"绝地学院"——"任何来自 Kavak 的人都可以参加，从 CEO 到 AI 工程师到机械师。"训练异常艰苦，Ali 亲自设计了这个项目，而且必须持续迭代，因为技术变化太快："你不能送这些人去斯坦福学这个，因为这些都是新东西，哪儿都没有现成的课程。"

六周后，学员们的"毕业项目"是把最新的 Agent 部署到生产环境。参与者来自各个部门：机械师、财务人员、工程师——"每个人都能做到。"当然，并非所有人都因此成为 AI 工程师（虽然有些人确实成了），但所有人都学会了如何与这项新技术协作。Ali 说得很直白："我们对大家说：没有退路了。这就是 Kavak 的方向，这就是公司未来的样子。你有两个选择：接受训练，掌握在这个新世界生存的技能；或者，如果这不适合你，你可以离开 Kavak。但这就是我们要走的路。"

结果是出乎意料的正面："我们强化了文化。每个人都非常兴奋。人们真的学会了如何构建 Agent 系统。" 今天，Kavak 的任何流程实质上都是 Agent 和人类的协作——"有时候 Agent 是人类的老板，有时候人类在设计 Agent。"

**个人感受**

Ali 在讲述绝地学院时流露出了明显的自豪感。这个项目不是在"管理变革"，而是在"发起一场全员运动"。最打动人的细节是他承认"我必须不断改造这个项目，因为一切变化太快"——这意味着作为项目设计者的他，自己也始终处在学习的前沿。这种"所有人都在同一条船上"的姿态，正是 Kavak 文化没有被 AI 转型撕裂的原因。

**延伸思考**

绝地学院的本质，是把"AI 转型"从一种自上而下的命令，变成一种自下而上的能力建设。很多公司把 AI 转型理解为采购工具或重组部门，但 Kavak 的做法揭示了一个更深刻的道理：**转型的真正单位是技能，而不是项目**。当一个机械师能亲手部署一个 AI Agent 时，他对变革的恐惧就已经被主角感替代了。

## 十一、组织架构：扁平化、超级授权、人类为 Agent 工作 `[对话·组织结构]`

**核心观点**

今天的 Kavak 组织呈现出"非常扁平、非常资深、超级授权"的形态。一个团队里可能同时有工程、AI、运营等角色，他们的职责分三类：构建 Agent、为 Agent 工作、或者在物理世界直接面对客户。中层管理的概念正在淡出。

**深度阐述**

主持人问了一个许多领导者都想问的问题：Kavak 有数千名员工（曾经），现在 Agent 处理了大部分事情，那么组织架构是什么样的？中层管理还存在吗？

Ali 的回答勾勒了一幅与两年前截然不同的画面："现在团队非常扁平，非常资深，超级被授权。你去看一个团队，里面有工程、AI、运营——什么都在一起。他们要么在构建 Agent，要么在为 Agent 工作，要么在物理世界里面对客户。"[对话中段]

这种转变当然需要大量的再培训。因为 2022 年或 2023 年，没有人知道怎么构建 Agent，没有人知道怎么辅助 Agent，更没有人知道"听从 Agent 的指令工作"是什么体验。面对物理世界和客户的方式也彻底变了——不是人类根据经验和直觉安排工作，而是 Agent 告诉人类优先级、帮助人类把工作做得更好。

主持人追问了一个关键细节：当 Agent 遇到无法处理的状况时，系统会怎么做？Ali 批评了许多大型 Agent 系统的常见做法："通常如果 Agent 撞墙了、无法继续了，它就会把这个案例发给二级人工支持，然后彻底忘掉它。这不管用，因为你没有闭环反馈——你没有生成数据去训练 Agent 做得更好。"

Kavak 的做法是：每个客户都有专属 Agent（数百万个），它们可以访问公司每一个 API 和技能（这些技能由人类构建）。当 Agent 撞墙时，它会调用一个 API 发出求助信号——"我 need help"。另一头接应的不是另一个软件，而是真实的人类专家。这形成了一个完整的反馈闭环：人类帮助 Agent ⟶ 结果记录 ⟶ 训练数据 ⟶ Agent 变得更强。"如果你把它画成组织架构图，它实际上是：人类团队拥有一个 Agent，而这个 Agent 带来了更好的结果。"[对话中段]

**延伸思考**

"为 Agent 工作"这个概念对很多人来说仍然带着一丝反乌托邦的色彩。但 Kavak 的实践证明，当 Agent 承担的是规划、记忆、优先级排序和流程管理时，人类反而能更专注于那些需要判断力、同理心和身体在场的工作。未来的组织架构很可能不是"人管人"或"AI 管人"的二选一，而是一种灵活的、随任务变化的混合指挥链。

## 十二、给领导者的直白建议：自上而下，不是黑客松 `[对话·领导者建议]`

**核心观点**

Ali 对大型机构领导者的建议只有两条：第一，AI 转型必须自上而下，而不是靠"黑客松"和"员工自发的 adoption"；第二，必须衡量真正重要的东西——尤其是每一枚 token 的质量，而不是笼统的使用量。

**深度阐述**

"我知道很多大型机构的领导者都在私下里找你咨询。"主持人半开玩笑地说，"你的答案可能会帮他们省掉很多电话。" Ali 没有客气，直接给出了两天建议。

**第一条：必须自上而下。** "如果只是靠自下而上的采用，什么都不会发生。因为员工很难凭空产生那种'品味'或战略感，来决定该构建什么、不该构建什么。" Ali 见过太多公司这样做："哦，我们办了个黑客松，大家提出各种用例，我们赞助其中一些——这根本不管用。"他用了军队的比喻："一支军队，如果每个人都自己决定战略和战术，上战场想干嘛就干嘛，那是打不了仗的。你需要非常清晰的战略，然后垂直地带领你的部队朝那个方向前进。"

领导者需要做的事是：非常明确地设定公司三到五年后应该长什么样，然后从这个未来倒推，开始构建。"这不是'我们可以尝试 AI'的阶段，这是一次转型。" Ali 强调。转型是强制性的、全员的、不可逆的——就像 Kavak 对全体员工宣布的那样：这是公司的方向，你可以选择学习，也可以选择离开，但公司不会回头。

**第二条：衡量真正重要的东西——token 的质量远超数量。** Ali 提出了一个三层 token 框架：

- **第三层（最优质）**：被 Agent 使用、直接产生组织工作的 token。"我知道每一枚 token 的 ROI——因为它服务于正在执行公司业务的 Agent。" Ali 说，"这对我来说是好消息：我正在增长，而且我知道每一枚 token 的价值。"
- **第二层（间接可测）**：开发者写代码时使用的 token，可以通过代码产出间接评估价值，然后推动它们进入生产环境。
- **第一层（大多数公司的现状）**：员工在 ChatGPT 或 Copilot 上随意使用的 token。"那些 token 到底产生了什么价值？我完全不知道。"

Ali 警告说："我见过很多公司花了几亿美元在 token 上，然后说'我们已经有 adoption 了'——但 adoption 不是目标，价值才是。"[对话后段]

**精华收获**

- 转型必须是一把手工程：设定清晰的未来图景，然后垂直推进
- 黑客松式的"用例征集"是伪装的惰性——真正难的是砍掉旧结构
- 对 token 支出要像对资本支出一样严格：每一枚 token 都必须能回答"它创造了什么价值"

## 十三、从"图"到"虚拟机"：两次推倒重来的勇气 `[对话·架构演进]`

**核心观点**

Kavak 曾构建了一整套基于"图编排 + 多 Agent 协作"的系统，这套系统已经让公司实现了盈利和增长。但当 Claude Opus 4.5 出现时，Ali 判断旧的范式已经过时，于是他们亲手摧毁了两年来的成果，换成了"一客一 Agent + 虚拟机 + 长期目标"的新架构。

**深度阐述**

Ali 给所有正在构建 Agent 系统的公司的建议是极其反直觉的："不要构建 agentic workflows——不要构建图、函数或目标编排。我们曾经构建过这些。"[对话后段]

Kavak 的经历是这样的：在 2024 年 12 月前，他们有成千上万个多 Agent 系统在生产环境中运行整个业务——把卖车流程拆成融资、购买建议、推荐等子任务，由不同 Agent 分工协作，通过图编排（graph orchestration）完成复杂目标。这套系统行之有效，让公司实现了盈利和惊人的增长。

但 Opus 4.5 的出现改变了一切。"我意识到这不是正确的范式了。现在智能的水平已经不需要图、多 Agent 格子化工作（lattice work）和复杂 harness 了——这些反而会约束这个级别的智能。"于是一个疯狂的决定诞生了：**摧毁他们两年多来构建的一切——那些正在让公司赚钱的系统——然后从头再来。**

"我们决定把已经带来盈利、带来惊人增长的东西全部推翻，用一个我们相信足够稳健、可扩展、能够利用递归自我改进和每个月新出的更强模型的 harness 重新开始。"[对话后段]

新架构的核心形态是：一个虚拟机 + 一个 Agent + 记忆 + evals + CLI（命令行界面）。Agent 通过 CLI 访问公司所有工具与 API，怀揣一个长期目标（比如"最大化这个客户的终身价值"），每天被实例化数十万次。

为什么这种转变如此重要？Ali 给出了一个宏大视角："经济价值在过去四千年里从来不是由个人交付的，而是由组织交付的。所以你想要自我改进的，不是单个 Agent，而是整个组织。"这就是"自我改进的组织"（self-improving organization）的含义：当新的更强模型发布时，整个组织的所有 Agent 都能立刻受益。"如果你让这个循环运转起来，让组织真正实现自我改进、不断利用每几个月就出现的新智能——你得到的就不只是智能的指数增长，而是公司所能创造价值的指数增长。"[对话后段]

**个人感受**

Ali 在讲述"摧毁一切"这个决定时，语气平静，但分量极重。亲手推翻一个正在盈利、正在增长的系统，需要巨大的勇气和清醒的认知。这是一种"昨天的成功是今天最大的敌人"式的选择——真正的 AI 原生组织不仅要敢于建新东西，还要敢于杀掉自己亲手养大的"好孩子"。这种决断力可能是 Kavak 与其他公司最本质的区别之一。

**延伸思考**

"自我改进的组织"是一个极具想象力的概念。大多数公司讨论 RSI（递归自我改进）时，关注的是模型本身；Kavak 把这个问题提升到了组织层面：让组织架构、数据反馈、评估体系、工具链全部围绕"模型能力每几个月跃升一次"这个前提来设计。这意味着组织的进化速度不再受限于人类的学习速度，而只受限于模型发布的速度。

## 十四、创造性破坏：电力的故事，正在 AI 时代重演 `[对话·宏观经济学]`

**核心观点**

经济学的"创造性破坏"理论预言的正是当下：老牌公司采用新技术时往往只做表面文章，获得 6-10% 的效率提升；而新公司从零开始围绕新技术设计整个组织，获得 3 倍甚至 10 倍的生产力跃迁，进而摧毁旧的市场格局。

**深度阐述**

Ali 敏锐地指出，AI 转型的最大机会并不属于那些艰难转型的既有公司，而属于可以"从零设计"的新公司。他引用了经济学家约瑟夫·熊彼特（Joseph Schumpeter）的"创造性破坏"（creative destruction）理论：创新不是通过现役公司采用新技术来冲击经济的，而是通过现役公司保持不变、新公司用新技术摧毁它们来实现的。短期看，这会破坏经济中的既有价值；长期看，更高效的新公司会给整个经济带来更好的产品和服务。

"这很难。" Ali 毫不讳言，一个大型甚至上市公司的 CEO，很难公开宣布："我赌上一切押注 AI，公司必须长成这个样子，我要把过去 40 年建立的东西全部毁掉重建，成为一个 AI 原生公司。"有多少 CEO 真的会在规模化阶段做出这个决定？所以，当大公司还在犹豫和"浅层采用"时，新公司完全可以围绕 AI 的优势从零构建，然后接管市场。

Ali 用电力革命的故事来说明这一点——这也是他经常讲给团队听的故事："福特生产线的技术诞生于 1879 年和 1881 年。爱迪生在纽约和伦敦开始商业化电力，他发明了效率极高的发电机。所以，你本来可以在福特之前 40 年就建起福特的工厂——技术在 40 年前就存在了。但当时人们采用电力的方式是：保留我的四层工厂、传动轴和皮带，只是把煤机换成电机——这会带来一些收益，但只有 6% 的效率提升。"

真正的做法是什么？"你必须摧毁那座工厂，把它建在平地上，不在纽约市中心，而是在康涅狄格州或新泽西州，然后围绕小型发电机和电力重新设计整个工厂——这样你才能获得 3 倍的生产力提升，正是这种生产力支撑了美国整个 20 世纪的增长。"电脑革命也是如此，今天 AI 革命依然如此："人们想采用 AI，却不愿重新设计整个公司。他们只是表面地采用它，最终得到的是 6% 或 10% 的改进，而不是 10 倍的改进。这就是工业规模的创新者困境。"

**个人感受**

Ali 讲这个故事时，语气像一位传教士。他的潜台词很明显：Kavak 选择了成为那个"摧毁工厂、在平地上重建"的公司。而对于那些躲在"我们正在谨慎试点 AI"背后的大公司，他几乎没有隐藏自己的不以为然——小心地采用 AI，本身就是最危险的选择。

**延伸思考**

电力的故事提出了一个尖锐问题：你的公司是在"换发动机"还是在"重建工厂"？很多公司把 AI 能力嵌入现有的流程中，获得的只是边际效率；而真正的 AI 原生公司会把 AI 作为组织的底层逻辑重新设计一切。对创业者来说，这个故事的启示是：**你的竞争优势不在于比老牌公司更懂 AI，而在于你没有需要保护的旧工厂。**

## 十五、给未来创始人的最后一课：去建，但要建得深 `[对话·尾声]`

**核心观点**

Ali 认为这是人类历史上最激动人心的创业时刻：过去只有巨头才能获得的世界级智能工具，现在几乎免费地向所有人开放。他的建议是：大胆去建，但要建得深——不要满足于表面应用，要想象一个围绕 AI 重建的世界。

**深度阐述**

当被问到对首次创业者或未来创始人的建议时，Ali 的回答充满了一种罕见的乐观主义："这是人类历史上最激动人心的时刻。我相信这一点。这也是成为创始人最激动人心的时刻——因为这是第一次，任何人都能以几乎免费的价格（或者说 20 美元一个月）获得世界上最强大的工具和智能。工具的民主化在人类历史上从未达到过这个程度。"

他提醒创业者，世界上有太多问题亟待解决，也有一个全新的现实等待被构建。他的具体建议是：去试试吧，但要深入（"go for it deep"）——想象一个以 AI 为中心的未来会是什么样子。他甚至给出了一个令人安心的思维框架："你甚至不需要假设指数增长。只要假设一个线性趋势——AI 会以线性速度持续变强——然后为那个世界构建产品。你会想出很棒的想法，给世界带来巨大的价值。"[对话尾声]

**个人感受**

访谈在一种澎湃的乐观中结束。Ali 没有给出"如何避免失败"的谨慎建议，而是给出了一个近乎信仰的召唤：技术民主化已经发生，未来属于那些敢于深入构建的人。对于一路走来经历了"超前十年"、亲手摧毁自己成果、让 AI 当 CEO 的 Ali 来说，这份乐观不是天真，而是用无数次冒险换来的判断。

## 精华总结：Kavak 剧本的七条核心法则

回顾整场对话，Kavak 的 AI 转型可以提炼为七条可迁移的法则：

1. **重建而非叠加**：不要给旧组织配上 ChatGPT 就当作 AI 转型；围绕 Agent 重建 API、流程和系统。
2. **把 Agent 放到最难的地方**：从销售而不是客服开始；如果 AI 能在最核心的创收环节胜出，其他环节只是时间问题。
3. **Evals 是速度的前提**：投入一半的资源构建评估体系，衡量真实商业结果，而非通话时长或 token 用量。
4. **一客一 Agent，长期目标驱动**：Agent 应该有记忆、有虚拟机、有长期的客户终身价值目标，而不是一次性的任务工作流。
5. **对 token 分层管理**：像管理资本一样管理每一枚 token 的 ROI 归属。
6. **全员再技能化**：绝地学院式的训练不是 HR 项目，而是转型战略的核心——每个人都要学会与 Agent 协作或构建 Agent。
7. **敢于杀死昨天的成功**：当模型能力跃升时，果断摧毁旧的 Agent 架构，即使它正在盈利——因为自我改进的组织，才是终极竞争优势。

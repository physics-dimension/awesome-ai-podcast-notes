# ChatGPT Work 完整指南：61分钟掌握95%的日常工作能力

## 引言：AI Agent 时代的工作革命

如果你正在使用 ChatGPT、Claude 或 OpenClaw，但仍然不清楚在商业场景中应该选择哪个 AI Agent、以及如何使用它，那么你来对地方了。在本视频中，我们将深入探讨如何有效利用 AI Agent 来完成实际工作。具体来说，我们要讨论的是 **ChatGPT Work**——OpenAI 推出的全新 Agent 工具。它类似于 Claude 的 Co-work 功能，但在我看来，ChatGPT Work 更好用，而且更易于在移动端、网页端、桌面端或任何其他平台上使用。

在本视频中，我们将逐一解析 **ChatGPT Work 的 14 项核心能力**，每项能力都会搭配真实世界的商业使用案例，让你在视频结束时，能够清楚知道它能做什么，以及它适合嵌入到你的工作流中的哪个环节。

## 背景：从 ChatGPT 到 Codex，再到 ChatGPT Work

在深入理解 ChatGPT Work 的工作原理之前，有必要先了解它的发展时间线。

**2022年**，ChatGPT 横空出世，成为全球性的病毒式热点。那是第一次有人将 AI 聊天机器人以人人都能使用的方式推向世界。在四年的时间里，ChatGPT 的周活跃用户增长到了近**10亿**。

随后，OpenAI 发布了一款名为 **Codex** 的新产品。Codex 是对 Claude Code 和 Claude Co-work 的直接回应。**Codex 基本上是第一款超级应用**——你可以打开 Codex 桌面应用，在其中构建任何东西：应用、演示文稿、视频编辑，基本上你能想到的任何事情都可以直接在 Codex 中完成。

因为 Codex 不仅能处理编码任务，它几乎能出色地完成所有知识型工作（knowledge work），再加上"Codex"这个名字听起来像是一个开发者工具，OpenAI 决定将 ChatGPT 应用和 Codex 应用合并为 ChatGPT。**ChatGPT Work 就此诞生**。

ChatGPT Work 在 Codex 发布约六个月后推出。你可以把 ChatGPT Work 理解为**一个更易用的 Codex**——但与 Codex 不同的是，ChatGPT Work 可以在网页端使用，可以在桌面应用中使用，也可以在 iOS 应用中使用。

## 能力一：创建精美的报告和文档

ChatGPT Work 的第一项核心能力是**创建精良的报告和文档**。

正如你所看到的，我在 ChatGPT Work 中创建了这份文档，它可以直接在 ChatGPT 应用内查看。让我演示一下流程：

- 打开 ChatGPT，新建一个对话，通常你会从聊天模式开始
- 切换到 ChatGPT Work 模式
- 输入这样的指令："你好，ChatGPT Work。我需要你制作一份麦肯锡风格的演示文稿，内容是关于今年剩余时间 AI 领域的未来预测。请做深入的研究，创建一份包含大量图形和时间线的麦肯锡风格报告，要看起来专业且出色。"

由于这是 ChatGPT Work，它会使用**云计算机**来创建文档所需的文件。随后，我们可以在侧边面板中打开它，文档就完成了。

以刚才的演示为例，ChatGPT Work 最终创建了一份 **19页的麦肯锡风格 AI 展望演示文稿**。在查看成果之前，我先展示一下它是如何工作的：

- 它实际搜索了 **87 个网站**（它会根据需要持续搜索互联网）
- 它阅读了演示文稿和库的说明、风格指南以及 API 文档
- 它工作了 **13 分钟 33 秒**
- 最终创建了这份演示文稿

这份文稿非常有图形化风格，讨论了各种不同的预测。

**编辑文档的方式也非常简单**：在侧边面板中打开文档，进入对话框区域，双击即可。你可以直接下达修改指令，比如：

"关于幻灯片一：'2026年余下时间'，我不明白这个图形想表达什么，请花些时间改进它，要有创意。幻灯片二上，我不喜欢这些胶囊形状的元素，看起来有点奇怪，请想办法调整得更专业一些。第五点里，我不喜欢这个黄色，能不能换成其他颜色？'自主将主宰一切，有范围且可逆'这行字请调大一点，换个颜色。第八点里，这个包含'7030亿'的色块很丑，请改变它的颜色。对于第五个预测，也就是幻灯片九，我想要一种不同的整体风格。把字体换得好一点。另外，我真的很喜欢幻灯片十七，它非常好。就这些，请完成以上所有修改。"

你可以把 ChatGPT Work 想象成一位同事，你可以把任何想法直接"唠叨"给它。由于这个 Agent 拥有一台计算机的访问权限，可以创建制作演示文稿所需的文件，它可以花足够的时间处理任务——它会处理你说的所有修改，并在 5 到 10 分钟内回复你。

**9分半钟后**，它完成了一大批修改。如你所见，现在首页的图形换了，我更喜欢新的这个。它去掉了那些胶囊元素，基本上完成了所有我希望的调整。

**开箱即用，ChatGPT Work 可以创建这些文档类型**（即使不连接任何外部工具）：

- **PPTX 演示文稿**（PowerPoint 格式）
- **DOCX 文档**（普通 Word 文档格式）
- **PDF 文件**
- **HTML 文件**（可直接在浏览器中打开）

请记住：**你在网页端 ChatGPT Work 上创建的每一种文档，都可以在 iOS 应用上打开**。

**一个小技巧：移动端语音编辑**。在手机上打开文档时，点击语音按钮，就可以直接用语音下达修改指令。例如：

"好的，我现在正在查看这个文档。请你扩展这部分内容，把表格做得稍大一些，增加一些它可以创建的内容。另外，请去掉'GPT Work 快速参考'这个副标题，把标题调大一点，增加一些视觉间距。我说的是那份 PDF 文档，请给我发一份新的 PDF。"

**2 分 13 秒后**，ChatGPT Work 就创建了新版本的报告。打开后可以看到修改确实生效了：副标题被移除了，其他部分得到了扩展，文档从一页变成了两页。

你可以反复进行这样的迭代——继续对着语音说"请让它更长，做成四页"，退出后发送指令即可。**你可以无限次地重复这个过程**。

## 能力二：使用插件（Plugins）扩展工具和能力

ChatGPT Work 的第二项核心能力是**通过插件添加更多工具和功能**。

你会在 ChatGPT Work 界面中看到一系列建议，这些建议都基于我的日历、电子邮件、Slack 以及我添加的所有插件。

**插件与技能（Skills）的区别**：

- **插件**是与其他应用和工具的官方连接，其他公司可以为 ChatGPT Work 创建插件，让你轻松连接 Codex、ChatGPT 或 ChatGPT Work
- **技能**则是更轻量的指令文件（将在能力十一中详细讨论）

查看已安装插件的方法很简单——点击插件按钮即可。以下是我在 ChatGPT Work 中使用的插件：

- **ClickUp** — 用于与管理团队沟通
- **Convex** — 用于涉及数据库的任何操作
- **Documents** — ChatGPT Work 内置的文档工具
- **FAL** — 让我可以使用所有流行的 AI 图像和视频模型
- **GitHub** — 对编码工作极为重要
- **Gmail** — 最重要的插件之一，我可以从 ChatGPT Work 完全控制 Gmail
- **日历（Calendar）**
- **Google Drive**
- **Hostinger** — 网站托管服务
- **Hyperframes（by Heyen）** — 用于创建高质量动态图形
- **Notion** — 笔记与协作平台

**实际应用示例**：假设我想查看邮件，"嘿，Emily 最近给我发过邮件吗？请告诉我她说了什么。"ChatGPT Work 会立即访问我所有的电子邮件。使用 Gmail 之类的插件时，插件本身会捆绑相应的技能，比如读取 Gmail 的技能。

它可以告诉我："她说请你对下面这个 Agent Native 播客的概念提供你的意见。"然后我可以回复："起草一封给 Emily 的邮件，告诉她我会在接下来的四五个小时内完成。我会更新 Notion 文档，然后把链接发给她。另外，请创建一个**一次性自动化任务**，设置为 6 小时后执行——如果届时我还没有发送邮件，就自动把链接发给她。"

在这里，ChatGPT Work 会起草 Notion 更新确认，创建定时任务。最终你确认发送后，它会在 17 秒内完成工作并发送邮件。在 Gmail 中可以看到邮件确实已发出："嘿 Emily，是的，我会在接下来的四五个小时内完成。我会更新所有内容到 Notion 文档，准备好后把链接发给你。"

**插件的智能调用**：你并不需要每次都使用 @ 提及（at-mention）来指定插件。ChatGPT Work 足够智能，可以根据上下文自动选择合适的插件。

**在移动端添加插件同样简单**：点击设置图标，找到插件选项，浏览并选择你想要添加的插件（如 Canva），一键登录并授权即可完成安装。

每个插件都带有**捆绑技能**（bundled skills）。例如 Canva 插件包含：Canva 品牌演示文稿、Canva 批量创建、Canva 翻译设计等技能。有些插件包含多达 50 个技能，有些只有 1 个，各不相同。你可以随时点击"在聊天中试用"来测试插件。

## 能力三：Blocks（块）—— 可编辑的结构化内容

ChatGPT Work 的第三项能力是**Blocks**，这是我个人认为被严重低估的功能。

**文本块（Text Block）**：例如，我可以让 ChatGPT Work 查看某期播客的 Notion 文档，为我撰写一个开场白，并要求它写成**可编辑的文本块**。这样，回复会出现在一个块中，我可以：

- 全屏聚焦查看
- 直接编辑内容（直接在块中打字修改）
- 让 AI 根据描述进行修改

在 iOS 移动应用上，同一对话中的块同样可以渲染和编辑。它甚至会给出**修改建议**，比如"用更有力的钩子开头"、"精简并删除重复内容"等。点击建议后，它会展示一个动画，显示具体的修改内容。你可以**在修改前后的版本之间切换**，这非常方便。

**图表块（Diagram Blocks）**：Blocks 的功能远不止文本。ChatGPT Work 还可以创建多种图表块：

- **思维导图（Mind Map）**：要求它创建一个 Mermaid 格式的思维导图来头脑风暴话题，它会将代码渲染成清晰的可视化图表
- **流程图（Flowchart）**：展示对话或流程的步骤
- **时序图（Sequence Diagram）**：描述用户与系统的交互过程，展示底层逻辑

例如，你可以让 ChatGPT Work "根据我给你的关于 ChatGPT Work 的 Notion 文档，带我了解普通用户的使用流程。我想要一个详细的时序图块，描述用户如何使用 ChatGPT Work，以及背后发生了什么——比如插件、技能和各种不同的事情。"

最终它会生成一个非常清晰的一页式时序图：用户描述期望结果 → ChatGPT Work 规划并执行 → 识别需求 → 将文件加载到内存和相关技能中 → 返回偏好和任务指令 → ChatGPT Work 模型选择插件或浏览器 → 工具从连接的来源返回信息（包括插件、技能和外部连接）→ 信息返回后进行研究、分析和创建或操作软件 → 最终组装文档、演示文稿、网站或应用。

**查询所有支持的块类型**：你可以直接问 ChatGPT Work："我们创建了思维导图、流程图和时序图。请列出你内置支持的其他所有类型的块。"它会展示所有类型——包括各类图表块、写作块（如邮件草稿块）、数据和技术块、媒体块，以及文件和应用程序块。所有这一切都可以直接在 ChatGPT Work 内完成，并且**所有块类型在手机上都可用**。

## 能力四：构建并托管完整的网站和应用

ChatGPT Work 的第四项能力是**构建和托管完整的网站和应用程序**。

你可以将前面创建的所有图表整合成一个**可分享的公共网站**。ChatGPT Work 可以直接在对话中构建和部署站点（称为 Sites 功能），这些站点就像**迷你应用**，可以与朋友、团队或任何人分享。

例如："请创建一个网站，展示我可以创建的不同类型的图表。把我们做过的那几个图表放入网站中，正确地渲染出来，展示它们的外观。我希望这是一个可以分享给朋友的 ChatGPT 站点。"

**6 分 10 秒后**，网站就创建完成了。它会部署在 chatgpt.site 域名上，展示"ChatGPT Work 可以在对话中渲染什么内容"——包括思维导图、流程图、时序图、时间线、用户旅程等。

需要注意的是，这种 ChatGPT 站点是**内部工具**，托管在 ChatGPT 的服务器上，并不是真正意义上的互联网链接。如果需要把它发布到公网，可以使用 **Vercel 插件**来部署，获得一个 vercel.app 链接。之后还可以通过 **Namecheap 插件**购买自定义域名，并让 ChatGPT Work 自动更新 Vercel 上的域名设置——**创建应用、发布到互联网、绑定自己的域名，全程都可以用对话完成**。

## 能力五：使用内置 GPT Image 2 模型编辑和生成图像

ChatGPT Work 的第五项能力涉及**使用内置的 GPT Image 2 模型编辑和生成图像**。

例如，我上传了一个视频缩略图的概念设计，可以这样指示："请把文字改成'ChatGPT Work is insane'，然后把 Logo 换成这个"——同时粘贴 ChatGPT 的图标——"只改这些东西，其他保持不变，做三个变体。"

ChatGPT Work 内置了当前最好的图像模型，在图像编辑方面表现出色。它还支持**内联编辑**：即使图像正在生成中，你也可以点击编辑图标，追加新的修改指令，比如"减少图标周围的光晕。左边的男士应该穿棕色衬衫，右边的男士穿蓝色衬衫。"

**更精细的评论功能**：点击图片，可以使用评论功能在特定位置添加修改意见，比如"头发更浓密一些"、"眼睛蓝色"、"发际线更好"、"胡子稍微多一点"、"牙齿更白"、"背景用深灰色渐变而不是纯黑"。发送后，ChatGPT Work 会在精确位置应用这些修改。

完成后，你可以**在多个版本之间切换对比**，查看每次修改前后的差异。

这些图像还可以**直接通过插件发送给同事**："请把这四个变体通过邮件发送给 Emily，我想知道她更喜欢哪个。"邮件会自动附上所有四个缩略图变体，并附上说明文字。

## 能力六：分支对话（Branching a Chat）

ChatGPT Work 的第六项核心能力是**对话分支**。

假设你正在创建一个展示图表类型的网站，但同时你也想把这个内容做成一个幻灯片演示文稿。这时候你可以使用 ` /branch chat` 命令，它会将当前对话的所有内容**自动分支为一个独立的聊天**。

- 你可以重命名分支后的对话，便于区分
- 使用 `/pin` 命令可以将重要对话**置顶**
- 分支后的对话可以各自独立处理不同的任务

例如，一个分支继续做网站图表，另一个分支将同样的内容转换成 PDF 演示文稿。**一个对话对应一个任务**，这就是按任务进行对话管理的方式。

## 能力七：桌面端本地模式与云端模式的区别

ChatGPT Work 的第七项能力是关于**不同平台的使用方式和配置**。桌面应用、iOS 应用和网页应用的工作方式非常相似，但桌面应用中的 ChatGPT Work 会根据你所选择的設置而有所不同。

OpenAI 将 Codex 应用和 ChatGPT 应用合并后，唯一的区别在于这个配置选项：

- **云端版（In the cloud）** — 与网页版基本一致，文件保存在云端，可以在所有设备间同步，对话可以在手机、桌面和网页间无缝切换
- **计算机版（On your computer / Local）** — 这是本地运行模式，不同之处在于：

  - ✅ 可以访问你电脑上的文件和桌面应用
  - ✅ 可以控制你的计算机
  - ✅ 可以本地保存文件到电脑
  - ✅ 可以使用你在 Codex 中创建的**本地技能**（如 YouTube 缩略图技能、Notion 视频数据库技能等）
  - ❌ 对话**不能**在其他设备上继续（因为需要电脑保持开启）
  - ❌ 比 Codex 更安全：不能运行终端命令，会更多地向你请求权限

**重要提示**：如果你希望对话可以在多个设备间延续，你需要选择云端模式、网页版或 iOS 应用。如果你希望 ChatGPT Work 控制你的计算机并本地运行，请选择桌面端本地模式。

在云端模式下，通过侧边面板可以同步查看所有对话。在手机上也可以继续完全相同的对话——**手机、桌面应用和网页应用三者完美同步**。

## 能力八：语音模式（Voice Mode）

ChatGPT Work 的第八项能力是**语音模式**。

在 ChatGPT Work 界面中，点击"开始新的语音聊天"按钮，即可进行**实时的、双向的语音对话**。这不仅仅是语音转文字，而是完整的语音交互体验。

**实际案例演示**：在语音模式下，你可以直接说：

"嘿，ChatGPT Work，你好吗？能不能帮我在 Notion 里打开那个视频数据库，叫做'ChatGPT Work 解释'？请用 Codex 浏览器打开那份 Notion 文档。"

语音助手可以实时响应、打开文档、修正错误（"不，你打开错了，应该只是一个叫'ChatGPT Work 解释'的文件"）并完成任务。

更进一步，你可以完全通过语音来**管理文档、编辑内容、调整格式**：

"请把第 12 个能力的小节删掉，因为我想保持 14 个能力的数量。把所有的标题都改成二级标题，颜色设为蓝色。在第 8 个能力下面加三条要点，概括我们刚才用语音实际操作的过程。加一个简洁的总结，用黄色高亮，作为这一节的最后一条要点。"

语音模式可以访问**所有已连接的插件**。例如：

"嘿，帮我查一下邮件，把联系过付费赞助的人整理成一个快速表格。"——它会立即创建表格。

"有一个叫 Miniax 的公司，请回复他们。用草稿技能创建一封回信，在 Codex 浏览器中打开，告诉他们我的价格是每个视频 25 万美元。"——它会起草好回复，打开在浏览器中供你审阅发送。

**所有你在手机或网页应用上创建的插件连接，都可以通过语音模式访问**。只要打开语音，任何可操作的事情都可以用语音控制。

## 能力九：通过 iOS 应用远程控制电脑上的 ChatGPT Work

ChatGPT Work 的第九项能力是**从 iOS 应用远程控制电脑上的 ChatGPT Work**——这可能是最酷的功能之一。

iOS 应用中有一个 **Remote（远程）选项卡**，可以将手机上的 ChatGPT 应用连接到电脑上的桌面应用。连接后，你可以使用**实时语音**按钮，直接与桌面上的 ChatGPT Work 对话。

**关键功能：语音主线程可以派生新的工作会话**。例如：

"我要你开启一个新的 ChatGPT Work 会话，命名为'Riley 的笔记'。"——电脑上会立即创建这个会话。

"现在，请对我在 Notion 中的最新视频做研究，看看我最近两周的视频，根据这些告诉我接下来应该做什么视频。在新的 ChatGPT Work 会话中完成。"

**30秒内，电脑上自动生成了一个新的工作会话**，名为"根据最近 Notion 视频推荐新视频"，并且已经开始了研究工作。

**日常使用场景**：每天我进入办公室，插上电脑，拿起手机出去散步 30 分钟：

- 一边走一边处理所有邮件
- 用语音跟这个会话对话
- 每遇到一个任务就说"为这个内容任务开启一个新的 ChatGPT Work 会话"
- 等散步回到电脑前，可能已经有四五个会话在运行，每个都完成了大量工作，有些甚至已经准备好了完整的草稿

这确实是一种**全新的工作方式**——你不需要坐在电脑前，就可以通过语音派生工作会话，让 AI Agent 帮你完成大量实际工作。

## 能力十：内置浏览器（In-App Browser）

ChatGPT Work 的第十项能力是最被低估的功能之一——**内置浏览器**。

你可以通过点击面板开始一个浏览器会话，也可以按 Command+T 新建浏览器标签页。这个浏览器是**完全功能的浏览器**，可以：

- **登录你的各种账户**（例如登录 X/Twitter、播客后台等）
- **直接在界面上发帖**
- 让本地版 ChatGPT Work 直接控制浏览器并为你执行操作

**导入 Cookie 和密码**是最重要的设置：点击三个点的菜单，选择导入 Cookie 和密码，从你之前使用的浏览器导入，这样 ChatGPT Work 就能**自动登录所有账户**。

**任务化组织方式**：ChatGPT Work 以任务为基础组织浏览器标签页。例如：

"根据我今天最近的活动和获得的洞察，想出 10 条推文。把它们放到一个 Google 文档中，然后在 Codex 浏览器的新标签页中打开。"

它会自动创建 Google 文档并在内置浏览器中打开。你还可以通过右键点击链接 → "在浏览器中打开"来手动控制。我强烈推荐养成**将所有外部链接都在内置浏览器中打开**的习惯——这样所有的任务、标签页、聊天会话都集中在同一个工作区，切换任务时一切都井然有序。

## 能力十一：技能（Skills）

ChatGPT Work 的第十一项能力是**技能**。

技能就是**让 AI Agent 完成特定任务的小型指令文件**。在 Codex 中，我创建了很多技能——比如 YouTube 缩略图技能、Notion 视频数据库技能等等。每个技能都代表一个我可以引用的小工作流，Agent 也可以根据情境自动判断使用哪个技能。

**关于技能，最关键的是区分两类**：

- **本地技能（Local Skills）**：在 Codex 或本地版 ChatGPT Work 中创建。只能被本地版 ChatGPT Work 访问。如果你在云端版 ChatGPT Work 中尝试使用，是找不到的。
- **云技能（Cloud Skills）**：在网页版、手机端或云端版 ChatGPT Work 中创建。这些技能可以在手机和网页应用中使用（因为它们都是云端版本）。

创建方法很简单。在云端版中直接说："创建一个名为'测试'的技能。它只是一个测试技能，什么都不用做。只要写'测试'就行。"ChatGPT Work 会创建技能文件（skill.md），你可以在外部浏览器中查看和管理它。

**一个期望**：希望 OpenAI 未来能将所有技能合并统一，让我们的技能可以在任何产品中使用。

## 能力十二：定时自动化任务（Scheduled Automations）

ChatGPT Work 的第十二项能力是**让 AI 在未来的特定时间自动执行任务**。这是一个很多人知道但没能有效利用的功能。

**核心思维方式**：与其自己在未来某个时间点手动检查，不如提前设置好规则，让 AI 到时候自动处理。例如：

- 我发一封邮件后，希望收到回复时能立即处理
- 我可以设置："从明天早上 9:00 开始，**每小时检查一次** Emily 是否有回复。她一回复，就把内容添加到那份 Notion 文档中。完成后，发送邮件到我另一个个人邮箱，因为我将不在办公室。"
- 或者："从周一开始，每隔三小时检查一次；如果收到回复，通知整个团队。"

**关键区别**：

- 如果你使用**本地版** ChatGPT Work 或 Codex，**定时任务不会运行**——因为你的电脑必须保持开机
- 如果你使用 **ChatGPT 应用或云端版** ChatGPT Work，任务**无论电脑是否开启都会运行**

我几乎所有的邮件都会使用这种工作流：发送紧急邮件需要快速回复或通知团队时，我会自动设置："在这些日子，每小时检查一次回复。如果有回复，通知团队成员。"AI 会定期检查邮件并把我需要处理的事情路由给需要帮助我的人。

## 能力十三：创建专业电子表格

ChatGPT Work 的第十三顶能力是**创建电子表格**。

前沿模型在制作电子表格方面的能力已经好得令人惊叹，尤其是当你要求它进行大量互联网研究或提供大量内部文档时。

例如："对微软、谷歌和苹果的增长做深入研究。做一个深入的对比，创建一份完整的详细报告，并为此制作一个电子表格。我要很多图表和高质量数据。"

ChatGPT Work 会创建包含以下内容的电子表格：

- 完整的数据集和战略对比
- 来源与核查记录
- 历史财务数据
- **执行仪表盘（Executive Dashboard）**
- 五年营收、资本支出、自由现金流等多种图表

后续编辑也很容易："请做一个仪表盘页面或某种封面页，色彩丰富、看起来有趣，并推荐我应该买入哪家的股票。之后，把这个转换成 Google Sheet。"

由于已经设置了 Google Drive 插件，ChatGPT Work 会自动创建 Google Sheet，直接点击打开即可查看完整的数据可视化。

## 能力十四：多 Agent 并行工作区

ChatGPT Work 的第十四项能力，也是最后一项——**多 Agent 并行工作区**。

你可以在电脑上同时打开多个不同的 ChatGPT Work 会话（全部运行在云端），同时处理多个不同的任务。由于 Agent 开始需要越来越长的执行时间，**多任务并行**变得非常必要。

**实际操作方式**：在桌面上同时运行四个 ChatGPT Work 窗口，每个窗口处理不同的任务：

- 一个在检查邮件（"Perplexity 的额度用完了？让我看看那封邮件说了什么"）
- 一个在写播客开场白
- 一个在生成图表
- 一个在响应邮件请求

**窗口管理技巧**：

- **双击窗口顶部栏**可以全屏展开该任务，再双击即可恢复到原来的位置
- 可以直接在对话中要求"在浏览器中打开"来处理外部链接
- 可以在多个任务之间快速切换，每个任务的所有相关标签页和上下文都保持完整

这就是我的首选工作方式——同时推进三四个任务，每个任务有自己的工作区、浏览器标签页和上下文。

## 总结：ChatGPT Work 能力全景

让我们回顾一下今天讨论的所有能力：

### 云端版能力（可在所有设备间同步）

1. **报告和文档创建** — 支持 PDF、DOC、电子表格、PPTX 等
2. **插件系统** — 一键连接 Gmail、Notion、Canva、Vercel 等数十种服务
3. **Blocks** — 创建可编辑的文本块、Mermaid 图表（思维导图、流程图、时序图等）
4. **网站和应用构建** — 在 ChatGPT 内建站，通过 Vercel 发布到公网并绑定自定义域名
5. **图像生成与编辑** — 内置 GPT Image 2 模型，支持内联编辑、评论修改、版本对比
6. **分支对话** — 从一个对话分支为多个独立任务
7. **多平台同步** — 手机、桌面、网页三端完美同步（云端模式）
8. **语音模式** — 实时双向语音对话，控制文档、邮件、Notion 等等
9. **远程语音控制** — 从手机 iOS 应用远程指挥电脑上的 ChatGPT Work 派生新任务
10. **内置浏览器** — 登录所有账户，导入 Cookie 和密码，实现任务化标签页管理
11. **技能** — 云技能可在所有云端版本中使用；本地技能只能在本地版使用
12. **定时自动化** — 设置未来任务自动执行（云端版无论电脑是否开机都会运行）
13. **专业电子表格** — 研究、数据分析、图表可视化，并可转换为 Google Sheets
14. **多 Agent 并行工作区** — 同时运行多个任务，高效管理

### 使用建议

- **编码和本地文件操作**：推荐使用 Codex（它有完全访问权限，能运行终端命令）
- **日常知识工作**：推荐使用云端版 ChatGPT Work，核心优势是**可以随时随地继续对话**
- **本地安全和受控操作**：使用本地版 ChatGPT Work（不能运行终端命令，但可以创建、编辑、删除文件，且会更多请求权限）
- **本地技能与云技能**：在 Codex/本地版中创建的技能只能在本地使用；在网页/手机上创建的云技能可以在所有云端设备上使用

请记住：**Codex 和本地版 ChatGPT Work 协同工作**；**云端桌面版、手机版和网页版 ChatGPT Work 共享技能和数据**。
